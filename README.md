# Core Platform

Modular platform: NestJS API Gateway + Laravel 13 modules + Next.js 15 frontend.

All business logic lives in independent Laravel modules (auth, users, tenants) connected via RabbitMQ. The Gateway is a thin router — JWT verify + RabbitMQ mutations (202 + SSE) + HTTP proxy for queries.

## Quick Start

```bash
git clone <repo> && cd core
cp .env.example .env
make jwt-keys     # generate RSA key pair
make dev          # start all services
make migrate      # run DB migrations
```

| Module | Responsibility |
|---|---|
| `auth` | Registration, login, JWT RS256 issuance, token refresh |
| `users` | User profile management |
| `tenants` | Tenant management |

## Architecture

- **Gateway** — NestJS 11, verifies JWT (RS256 public key), routes mutations to RabbitMQ (async, 202 + SSE job stream), proxies queries via HTTP
- **Modules** — Laravel 13 + hexagonal DDD (Domain / Application / Http / Infrastructure), outbox pattern, OpenAPI generated by dedoc/scramble
- **Async results** — `GET /api/jobs/:jobId/stream` (SSE, 60s timeout, Redis-backed job state)
- **Database** — PostgreSQL 16, separate schema per module
